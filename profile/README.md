## Core KDiff3 Features

- **Two or Three Paths:** Compare files or folders you are allowed to read, and see which side changed.
- **A Readable Diff:** Open a text difference and look at the lines before you copy anything.
- **A Direction You Choose:** Merging or copying writes. Do it only after you have named which side is the good one.
- **A Second Look:** Run the compare again after a copy. The list of differences should shrink.

---

## About KDiff3

KDiff3 shows how two copies of your work differ. A project and its backup, or two exports that should match, are the usual pair. It does not decide the correct version by itself, and it does not belong on someone else's home folder. A compare is safe. A merge that overwrites is not, until you have said which file wins.

Start with a small folder. A filter that hides files can make the result look clean when a difference is still there. If you do not understand the filter, turn it off. Binary files may only show as different. You do not need a hex dump of a program you do not own.

If both copies are wrong, the diff will not invent a third correct file. A spare on another disk is the real backup. Do not delete the older side the same hour if you are unsure.

## Tool Benefits

- **See Before You Copy:** The lines or the file list are visible first.
- **One Winning Side:** You choose the direction instead of hoping a sync guessed well.
- **A Check Afterward:** A second compare tells you the copy landed.

## Getting Started with KDiff3

Prerequisites: Two folders or two files you can explain, and a decision about which one should win if you copy.

1. **Pick Left and Right:** Point each side at a real path. Confirm them in Explorer if the names are similar.
2. **Compare:** Read one difference. Do not merge the tree on the first click.
3. **Copy Only What You Mean:** One file, or a direction you have written down.
4. **Compare Again:** The remaining differences should be ones you chose to keep.

---

## Professional & Personal Use Cases

- **A Backup Check:** See whether the spare folder still matches the project.
- **A Merge of Your Own Drafts:** Keep the paragraph you want from each copy of a text file you wrote.
- **A Release Folder:** Confirm an export matches the set you meant to ship.
- **A Stop:** If a file is only on the backup, recognize it before you copy it back over a deliberate delete.
